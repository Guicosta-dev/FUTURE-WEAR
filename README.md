# FUTURE//WEAR 🛍️

**Um projeto de e-commerce de roupas desenvolvido durante meus estudos de Python e Django.**

O FUTURE//WEAR é uma loja virtual criada para praticar desenvolvimento web, organização de aplicações Django, integração com banco de dados e funcionalidades comuns em um e-commerce.

Este projeto faz parte da minha evolução como desenvolvedor e representa a aplicação prática dos conhecimentos que venho adquirindo.

## 🎯 Objetivo do projeto

Desenvolver uma loja virtual funcional enquanto aprofundo meus conhecimentos em Python, Django, banco de dados e desenvolvimento web.

## 🚀 Funcionalidades

- Catálogo de produtos.
- Página de detalhes dos produtos.
- Exibição de preços, descrições, categorias, tamanhos, cores e estoque.
- Cadastro de usuários.
- Login e logout.
- Carrinho de compras com gerenciamento de quantidades.
- Cálculo do subtotal e total do carrinho.
- Painel administrativo para cadastrar, editar e excluir produtos.
- Controle de estoque dos produtos.

## ⚙️ Como executar o projeto localmente

### 1. Clone o repositório

```bash
git clone https://github.com/Guicosta-dev/FUTURE-WEAR.git
```

### 2. Entre na pasta do projeto

```bash
cd FUTURE-WEAR
```

### 3. Crie e ative um ambiente virtual

Windows:

```bash
python -m venv venv
venv\Scripts\activate
```

### 4. Instale as dependências

```bash
pip install -r requirements.txt
```

### 5. Configure as variáveis de ambiente

Crie um arquivo `.env` na raiz do projeto, seguindo as orientações do arquivo `.env.example`.

Preencha as variáveis necessárias para sua configuração local. Não compartilhe chaves secretas ou credenciais no repositório.

### 6. Execute as migrações

```bash
python manage.py migrate
```

### 7. Inicie o servidor

```bash
python manage.py runserver
```

Acesse no navegador:

`http://127.0.0.1:8000/`
